# PORNIC — 両国のベーカリー＆カフェ ポルニック

## GitHub Pages に配置する
1. ZIP を展開し、index.html、assets フォルダー、README.md をリポジトリの直下に置き、main にコミットします。
2. Settings → Pages → Build and deployment で「Deploy from a branch」を選び、main と /(root) を指定して Save を押します。
3. デプロイが完了したら Settings → Pages に表示される URL を開きます。

HTML と CSS の静的サイトです。ビルドや API キーは不要です。手元では index.html をブラウザーで開けます。

## 店舗向けの更新
本文・営業時間・電話・地図は index.html、配色・余白・スマホ表示は assets/style.css で編集できます。番号を変更する際は tel: のリンクも更新してください。

写真は assets/interior.webp（店内）と assets/storefront.webp（外観）です。いずれもZIPに同梱しています。
